# Meme Lab — выпуск в Яндекс Играх

Этот файл фиксирует release-процесс для версии, которая собирается из `main`.

## Что уже автоматизировано в репозитории

- SDK подключается через обязательный для ZIP-хостинга путь `/sdk.js`.
- Локальная разработка проксирует `/sdk.js` на официальный сервер SDK.
- Game Ready (`LoadingAPI.ready`) отправляется после инициализации SDK и загрузки сохранения.
- Язык пользователя читается из `ysdk.environment.i18n.lang`; текущая локализация игры — `ru`, для остальных языков используется русский fallback.
- Обработаны `game_api_pause`, `game_api_resume` и `visibilitychange` для остановки/возобновления звука и разметки геймплея.
- Rewarded/fullscreen-реклама использует актуальную структуру `{ callbacks: ... }`.
- В production отключено получение наград через локальную fake-рекламу, если SDK не загрузился.
- Сохранения пишутся в LocalStorage сразу и синхронизируются с `Player.setData` с throttling, чтобы не превышать лимиты SDK.
- При старте сравниваются локальное и облачное сохранения; выбирается более свежая копия.
- Перед облачной записью проверяется безопасный размер payload.
- Vite собирает переносимый bundle с относительными asset-путями.
- Production release автоматически проверяется скриптом `scripts/validate-yandex-build.mjs`.
- GitHub Actions собирает готовый `meme-lab-yandex.zip`, где `index.html` находится в корне архива.

## Локальная проверка

```bash
npm ci
npm run build:yandex
npm run preview
```

`npm run build:yandex` выполняет TypeScript-проверку, Vite build и release-validator.

## Готовый ZIP через GitHub Actions

После push в `main` запускается workflow **Yandex Games Release**.

1. Откройте GitHub → Actions → `Yandex Games Release`.
2. Откройте успешный run для нужного commit SHA.
3. В Artifacts скачайте `meme-lab-yandex-<sha>`.
4. Внутри находится `meme-lab-yandex.zip` — его можно загружать в Консоль Яндекс Игр.

ZIP создаётся из содержимого `dist/`, поэтому в корне архива находится `index.html`, а не папка `dist`.

## Что проверить в черновике Яндекс Игр

- Название: **Meme Lab**.
- Основной язык: **Русский**.
- Платформы: отмечайте Desktop/Mobile только после проверки соответствующей версии в preview.
- Обязательно отметить, что игра использует облачные сохранения (`Player.setData`).
- Включить рекламную монетизацию, если rewarded ads должны работать в production.
- Не включать обязательную авторизацию: игра должна запускаться гостем.
- Проверить ориентацию и размеры игрового окна на реальных мобильных устройствах.

## Материалы карточки

Подготовьте актуальные материалы в соответствии с полями Консоли Яндекс Игр:

- иконка игры;
- обложка;
- минимум два скриншота для каждой заявленной платформы;
- короткое gameplay-видео, если поле обязательно в текущей версии Консоли;
- описание игры;
- инструкция «Как играть».

Не используйте в промоматериалах админку, debug UI, стороннюю рекламу или элементы браузера.

## Сценарий QA перед отправкой на модерацию

1. Первый запуск гостем — игра открывается без логина и без ошибок Console.
2. Дождаться появления игрового UI и убедиться через debug-панель, что Game Ready получен.
3. Пройти первый merge и изменить прогресс.
4. Перезагрузить страницу — прогресс должен восстановиться.
5. Проверить облачное сохранение на авторизованном пользователе.
6. Сделать более свежий локальный прогресс и убедиться, что старая cloud-копия его не перетирает.
7. Запустить rewarded-рекламу на монеты — награда выдаётся только после `onRewarded` и только один раз.
8. Проверить rewarded-рекламу на бустер и бонусный spin колеса.
9. Во время рекламы звук игры должен быть остановлен; после закрытия — корректно восстановиться.
10. Переключить вкладку/свернуть окно — звук прекращается; после возврата восстанавливается.
11. Проверить mobile portrait/landscape, если обе ориентации заявлены.
12. Проверить отсутствие context menu/drag UI при правом клике и long-press.
13. Проверить Settings, Daily Reward, Quests, Wheel, Shop, Inventory, Lab и Territory.
14. Убедиться, что админка и внутренняя аналитика выключены.
15. Убедиться, что build-validator завершился зелёным статусом.

## После модерации

Каждое обновление игры делайте через `main`: после push GitHub Actions создаст новый ZIP с SHA коммита. Загружайте новый artifact в существующий черновик/релиз Яндекс Игр и повторяйте smoke-QA перед отправкой новой версии.
