# 🧪 Meme Lab (V 1.2) — G3R

> **Жанр**: 2D Browser Merge & Idle Simulator  
> **Разработчик**: Разработано командой **G3R**  
> **Версия**: `Meme Lab V 1.2`

---

## 📖 О проекте

**Meme Lab** — увлекательная браузерная игра в жанре казуального скрещивания (Merge/Craft) и инкрементального развития (Idle Tycoon). Игроки смешивают различные категории элементов (животные, фрукты, бытовые предметы и космические материи) в футуристической алхимической лаборатории для создания уникальных, забавных покемемов (Бананокот, Капибара с чаем, Неоновый кот, Акула на скейте и десятки других).

Каждое открытое существо можно разместить на своей интерактивной полянке, гладить его для получения бонусов, повышать уровни, открывать новые биомы и расширять территорию до 25 питомцев.

## ⚙️ Единый конфигурационный файл (`src/config/gameConfig.ts`)

Все параметры игры, экономики, таймеров и интерфейса собраны в одном главном файле:  
📂 **`src/config/gameConfig.ts`**

Вы можете легко настраивать поведение игры без необходимости изменять код компонентов.

### Основные разделы конфига:

| Секция | Параметр | Описание | Значение по умолчанию |
| :--- | :--- | :--- | :--- |
| **`meta`** | `appName` | Название игры | `"Meme Lab"` |
| | `version` | Версия игры | `"V 1.2"` |
| | `author` | Разработчик | `"Разработано командой G3R"` |
| **`features`** | `enableAdminPanel` | Включение / отключение вкладки **Админки** в настройках | `true` *(поставьте `false` для скрытия)* |
| | `enableAnalytics` | Включение / отключение **Аналитики** и её вкладки | `true` *(поставьте `false` для выключения)* |
| | `enableRandomEvents` | Автоматический спавн случайных событий | `true` |
| | `enableAutoSave` | Автосохранение в LocalStorage | `true` |
| **`economy`** | `starterCoins` | Начальное количество монет | `200` |
| | `priceMultiplier` | Множитель цены прокачки существ | `1.25` |
| | `incomeMultiplier` | Прирост дохода за каждый уровень | `0.25` (+25%) |
| | `offlineMaxHours` | Лимит часов накопления оффлайн дохода | `8` ч. |
| | `coinMagnetBonusMultiplier` | Бонус перка «Мемный магнит» к доходу | `1.25` (+25%) |
| | `happyFlaskBonusMultiplier` | Бонус перка «Колба мудрости» к опыту | `1.5` (+50%) |
| | `goldenTouchClickMultiplier` | Бонус перка «Ласковая лапа» за клик | `5` (x5) |
| **`groundItems`** | `despawnSeconds` | **Время жизни предметов на полянке** (исчезают через N сек) | `15` сек |
| | `regularSpawnIntervalSec` | Обычный интервал появления предметов | `8` сек |
| | `fastSpawnIntervalSec` | Ускоренный спавн предметов с бустером | `4` сек |
| | `maxGroundItems` | Максимум предметов на земле одновременно | `6` |
| **`randomEvents`** | `initialMinDelayMs` / `Max` | Задержка перед самым первым ивентом | `8–14` сек |
| | `cycleMinDelayMs` / `Max` | Интервал между последующими ивентами | `35–75` сек |
| | `buffDurationMinutes` | **Длительность положительных баффов** (Карнавал) | `2` мин |
| | `debuffDurationMinutes` | **Длительность дебаффов** (Сонный туман) | `2` мин |

| | `adRewardCooldownHours` | Кулдаун бесплатной награды 1000 монет | `3` часа |
| **`audio`** | `defaultSoundEnabled` | Звуковые эффекты включены | `true` |
| | `defaultVolume` | Громкость по умолчанию (0–100%) | `75`% |

## 🎮 Игровые механики и возможности

1. **🧪 Лаборатория слияний (Merge & Mutations)**:
   - Скрещивание двух ингредиентов для синтеза новых мемов.
   - Поддержка точных рецептов, альтернативных комбинаций и умных генетических мутаций.
   - Окно получения существа с кнопками мгновенного размещения или сохранения в рюкзак.
   - Защита от переполнения: кнопка «Разместить» блокируется, если на полянке нет свободных мест.

2. **🏞️ Территория и зоны размещения (Idle Income)**:
   - 5 тематических биомов (Зелёная Поляна, Тропический Пляж, Неоновый Киберпарк, Лавовые Земли, Космический Оазис).
   - Расширение лимита существ с 5 до 25 слотов.
   - Интерактивное поглаживание существ со звуковыми реакциями и бонусами монет.

3. **🍎 Дикие ингредиенты на карте**:
   - Предметы появляются каждые 8 секунд (или 4 с бустером).
   - Таймер жизни каждого предмета составляет **15 секунд**, после чего предмет исчезает.
   - Перк «Дрон-Автосборщик» автоматически вакуумирует все предметы 24/7.

4. **🎲 Случайные события (Положительные и Происшествия)**:
   - Автономный запуск каждые 35–75 секунд.
   - Положительные: *Мемный Карнавал (x2 доход на 2 мин)*, *Бродячий покемем в рюкзак*, *Золотой метеорит*, *Космическая посылка*.
   - Негативные: *Сонный туман (-30% дохода на 2 мин)*, *Побег испуганного питомца*, *Нашествие енотов*, *Авария в лабе*, *Штраф мемного надзора*.

5. **🔊 Звуковая подсистема**:
   - Встроенный мастер-ползунок громкости (0–100%) в окне настроек.
   - Процедурный Web Audio синтезатор для чиптюн-музыки и эффектов.

## 🛠️ Управление и Панель разработчика (Админка)

В окне настроек (кнопка ⚙️ в верхнем углу) доступны:
- **🔊 Звук**: Ползунок общей громкости, тумблеры SFX и музыки.
- **🛠️ Админ**: Выдача монет, ингредиентов, разблокировка всех 5 зон, тест случайных ивентов, сброс сохранения.
- **📊 Аналитика**: Журнал игровых событий в реальном времени.

> *Примечание:* Отображение вкладок Админки и Аналитики можно в любой момент отключить через параметры `features.enableAdminPanel: false` и `features.enableAnalytics: false` в файле `src/config/gameConfig.ts`.

## 🚀 Стек технологий
- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons.
- **State Management**: React Context API с автосохранением и проверкой версий.
- **Audio Engine**: Web Audio API (Master Gain, Dynamic Synthesizers).
- **Сборка**: Vite.
